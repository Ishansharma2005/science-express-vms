# Science Express — Visitor Management System

A lightweight, offline-capable Visitor Management System built for Science Express.
Works fully in the browser using HTML, CSS and JavaScript.  
Supports webcam photo capture, CSV export, search, and badge printing.

## Features
- Visitor check-in with Name, Contact, Organization, and Purpose
- Webcam-based photo capture
- Modern UI with clean design
- Offline data storage using `localStorage`
- CSV export of all visitor records
- Printable visitor badge
- Search bar (by name, org, or ID)

## How to Run
Just open `index.html` in any modern browser:
- Google Chrome  
- Microsoft Edge  
- Firefox  

No server or installation required.
